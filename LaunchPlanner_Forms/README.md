# LaunchPlanner
A simple Winforms application to plan the launch of programs or the reading of documents or multimedia. It allows you to create launch plans, to start the intended document at the set instant. One can specify the name of the event, the date and time of the launch, the path to the program or document to be launched. The application will then launch the specified program or document at the specified time.

If the document is a multimedia file the system will use the default media player to open it. In general, when a document is launched, the application will use the associated application to open it.

If the document is a Web URL, the application will use the default web browser to open it and navigate to the URL.

The application also allows you to edit or delete existing launch plans, and to view a list of all scheduled launches. It is a simple and useful tool for anyone who wants to automate the launching of programs or documents at specific times.
